# Architecture Rules

Every HTML page should contain

- semantic HTML
- no inline CSS
- no inline JavaScript

Use the minimum number of meaningful classes required for stable styling,
behavior, and component reuse.

Do not remove classes solely to reduce their count.

Avoid:

- presentationless wrapper classes;
- autogenerated classes;
- redundant aliases;
- selectors tightly coupled to DOM depth.

SCSS

Shared UI

src/scss/components

Page specific

src/scss/pages

Variables

src/scss/utils/_variables

Layout

src/scss/layouts

Base styles

src/scss/core

JavaScript

Common functionality

src/js/main.js

If JavaScript becomes large,
split into modules.

Never duplicate HTML fragments.
