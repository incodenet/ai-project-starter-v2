Atoms · Tabs

Filter tabs

The listing filter used on every Insights hub: uppercase labels on a baseline, the active one carrying a violet underline. Two modes, one class set, one component.

01, Live component

Filter Tabs

Import it instead of hand-writing a tab row: <dc-import name="Filter Tabs" mode="dark" items="{{ tabs }}">. It keeps its own selection, calls onChange(key), and also fires a bubbling hi:tabchange event so a page can filter its own cards.

Dark hero row

Filter Tabs · mode="dark"

Sits at the bottom edge of a hub hero, 20px to the baseline, 3px violet underline. No supporting rule: the hero band ends where the tabs do.

Blog hub, hero

Light listing row

Filter Tabs · rule = true

Above a feed on white, 16px to the rule. The 2px supporting gradient runs the full width and fades to the right; the active tab overlays it with 2px of #7B52C7.

News hub, listing

02, Classes

Names to reference

Declared in assets/css/hi-typography.css, so a page can use the markup directly when it needs its own behaviour. The component above renders exactly this.

Bar

.tabs

Flex row, baseline aligned, gap 14px clamp(22px,2.6vw,40px). Modifiers: .tabs--light | .tabs--dark, .tabs--rule.

Tab

.tabs_item

13px / 700 / .12em uppercase. Two calibrations, both taken from the live hubs: light 16px to the rule with a 2px underline, dark 20px to the baseline with a 3px underline (padding drops 1px so the baseline holds).

Dark ink

.tabs--dark

Rest rgba(255,255,255,.5), active white with a 3px #9d73ff underline. Light mode: #6b6b76 → #15131c with 2px #7B52C7.
