Button library

Every variant is shown in the active mode. Columns are the size scale, each labelled with its type size and real pill height, on a 4px grid shared with icon-only. Flip the toggle to compare the same variant on the other surface, so the two modes never drift apart.

At this width LG (60) and XL (68) are dropped to keep the grid readable; widen the window to see all five.

Narrow screen: the size columns stack, so each variant lists its sizes in order XS → XL. Widen the window for the labelled grid.
