Design System · Icons

Icon Library

One set across the whole site: Lucide, 24px grid, 2px round strokes, currentColor. Click any icon to copy its SVG.

Grid

All icons live on a 0 0 24 24 viewBox. Never redraw at another size.

Stroke

stroke-width: 2, round caps & joins, fill: none.

Colour

Always currentColor, the icon inherits its parent's text colour.

Exception

Social brand marks are filled glyphs, not strokes, brand recognition wins.

How icons go into buttons

Three slots on the Button

Pass the raw SVG string into iconLeft or iconRight. The Button normalizes it to Lucide defaults automatically (strips hard-coded sizes, forces 2px round strokes) and centers it against the label, so you can paste an icon straight from lucide.dev.

<!-- icon on the left -->
<dc-import name="Button" label="Icon left"
  iconLeft="<svg viewBox='0 0 24 24' …>…</svg>"></dc-import>

<!-- icon on the right -->
<dc-import name="Button" label="Icon right"
  iconRight="<svg …>…</svg>"></dc-import>

<!-- built-in arrow shortcut -->
<dc-import name="Button" label="Read more"
  arrow="{{ true }}"></dc-import>

<!-- round icon-only button -->
<dc-import name="Button" iconOnly="{{ true }}"
  iconLeft="<svg …>…</svg>"></dc-import>
