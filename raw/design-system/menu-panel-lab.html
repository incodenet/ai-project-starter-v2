Rules

These values are the contract for the menu rows (.menu_row*), so a CSS build and a Design Component build look the same.

  • Panel — 650px / 2 columns for a full menu, 400px / 1 column for a short one. Radius 22, border #ece7f4, padding 14, grid gap 2, shadow 0 30px 70px rgba(24,10,43,.22).
  • Row — padding 12, radius 24, gap 14. Hover fills #f2f2f4 over .2s.
  • Icon tile — 56px, radius 12, gradient 135deg #F1F1F4 → rgba(241,241,244,.14). On row hover it turns solid white and lifts on 0 4px 10px -4px rgba(24,10,43,.14), 0 1px 3px -1px rgba(24,10,43,.1).
  • Type — title 16/600 #15131c, description 13/400 #6b6b76, line-height 1.35, 3px apart.
  • Chevron — fades in and slides 3px on hover. It carries margin-right:-15px so it never pushes a long title onto a second line.
  • Footer link — optional, spans all columns, 15px padding, radius 14, #f7f4fd → #efe8fb on hover, accent #7B52C7. Pass an empty footerLabel to drop it.
  • Mounting — the panel is absolutely positioned and hidden; the header animates opacity, transform and visibility on hover. docked pins it open in normal flow for sheets like this one.
