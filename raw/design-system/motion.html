Foundations · Motion

How content arrives

The reveal system from Services v2, written down: five entrance kinds, one easing, one timing set, and the loop that drives them. Every new page uses these values, not new ones.

01, Principles

Nine rules

Follow these and a new page moves like the rest of the site without any new decisions.

01

Reveal blocks, not words. One data-reveal per meaningful unit: eyebrow, headline, paragraph, button, card. Never on every span inside a paragraph.

02

One easing for entrances: cubic-bezier(.16,1,.3,1). It is the site's voice, everywhere, including hovers.

03

Durations are fixed: opacity .8s, transform .9s, masked headline lines 1.1s. Hover states are faster: .2s–.4s.

04

Stagger only where items are siblings: .12s per headline line, .08s per popping tile. No stagger between unrelated blocks.

05

Trigger at 92% of the viewport height — the element starts moving just before it is properly on screen. Inside a scroll-linked fade block the threshold tightens to 60%.

06

Drive it from a rAF loop, not IntersectionObserver: IO is unreliable in this host. One loop reads all rects per frame.

07

Entrances play once. Only marked replay sections (Spotlight, FAQ, CTA) re-hide when fully out of view so the entrance plays again on the next pass.

08

Respect prefers-reduced-motion: everything renders visible immediately, no transforms, ambient loops off.

09

Keep a failsafe: every 600ms, anything in view still computing to opacity:0 is forced visible. A paused transition must never hide content.

03, Timing

The numbers

Entrance transition

opacity .8s · transform .9s

Applied to every reveal element up front, so showing it is only a property flip.

/* set once, at init */
el.style.transition =
  'opacity .8s cubic-bezier(.16,1,.3,1), ' +
  'transform .9s cubic-bezier(.16,1,.3,1), ' +
  'letter-spacing .9s ease';

Staggers

.12s lines · .08s pops

Headline lines use a transition delay per line; pops use a running index across the page.

inner.style.transition =
  'transform 1.1s cubic-bezier(.16,1,.3,1) ' + (i * 0.12) + 's';
el.style.transitionDelay = (popIdx++ * 0.08) + 's';

Hover & state

.2s–.45s

Label swap .4s, tab underline .45s, colour and background .25s, tile shadow .2s, image zoom .5s–.6s.

/* label swap, shared with .hi-tab and Button */
transition: transform .4s cubic-bezier(.16,1,.3,1);
/* image inside a card */
transition: transform .5s cubic-bezier(.16,1,.3,1);  /* hover: scale(1.03) */

Ambient loops

@keyframes hi_*

Slow, low-contrast, infinite: hi_dottwinkle 4–9s, hi_floaty 6s, hi_scrollcue 1.6s, hi_marquee linear. All off under reduced motion.

04, Implementation

Drop-in engine

Paste into the page's logic class, call initReveals() from componentDidMount, and run the frame loop. This is the same code as Services v2, News, Blog and Events.

componentDidMount() {
  this.reduce = !!(window.matchMedia &&
    window.matchMedia('(prefers-reduced-motion: reduce)').matches);
  this.initReveals();
  const loop = () => { this.frame(); this._raf = requestAnimationFrame(loop); };
  this._raf = requestAnimationFrame(loop);
}
componentWillUnmount() { cancelAnimationFrame(this._raf); clearInterval(this._fs); }

initReveals() {
  const root = this.rootRef.current; if (!root) return;
  let popIdx = 0;
  root.querySelectorAll('[data-reveal]').forEach(el => {
    const k = el.getAttribute('data-reveal');
    el.style.transition = 'opacity .8s cubic-bezier(.16,1,.3,1), transform .9s cubic-bezier(.16,1,.3,1), letter-spacing .9s ease';
    // reduced motion: content is simply there
    if (this.reduce) { el.style.opacity = '1'; el.setAttribute('data-rv', 'shown'); return; }
    if (k === 'rise') {
      // every [data-riseline] gets an inner span it can slide inside
      if (!el.__riseInners) {
        const mk = (host) => {
          const inner = document.createElement('span');
          inner.style.display = 'block';
          inner.style.paddingBottom = '.14em'; inner.style.marginBottom = '-.14em';
          while (host.firstChild) inner.appendChild(host.firstChild);
          host.appendChild(inner); return inner;
        };
        const lines = Array.from(el.querySelectorAll('[data-riseline]'));
        if (lines.length) el.__riseInners = lines.map(l => {
          const i = mk(l); l.style.display = 'block'; l.style.overflow = 'hidden'; return i;
        });
        else { el.style.overflow = 'hidden'; el.__riseInners = [mk(el)]; }
      }
      el.style.opacity = '1';
      el.__riseInners.forEach((inner, i) => {
        inner.style.transition = 'transform 1.1s cubic-bezier(.16,1,.3,1) ' + (i * 0.12).toFixed(2) + 's';
        inner.style.transform = 'translateY(110%)';
      });
      el.setAttribute('data-rv', 'hidden'); return;
    }
    el.style.opacity = '0';
    if (k === 'up') el.style.transform = 'translateY(40px)';
    else if (k === 'pop') { el.style.transform = 'scale(.82)'; el.style.transitionDelay = (popIdx++ * 0.08) + 's'; }
    else if (k === 'card') el.style.transform = 'rotate(-6deg) scale(.72)';
    else if (k === 'spread') el.style.letterSpacing = '0';
    el.setAttribute('data-rv', 'hidden');
  });
  // failsafe: nothing in view may stay invisible
  clearInterval(this._fs);
  this._fs = setInterval(() => {
    const r = this.rootRef.current; if (!r) return;
    const vh = window.innerHeight;
    r.querySelectorAll('[data-reveal]').forEach(el => {
      const rc = el.getBoundingClientRect();
      if (rc.top < vh * 1.05 && rc.bottom > -40 && getComputedStyle(el).opacity === '0') this._show(el);
    });
  }, 600);
}

_show(el) {
  const k = el.getAttribute('data-reveal');
  el.setAttribute('data-rv', 'shown');
  el.style.opacity = '1';
  if (k === 'rise') { (el.__riseInners || []).forEach(i => { i.style.transform = 'translateY(0)'; }); return; }
  if (k === 'spread') el.style.letterSpacing = '.3em';
  else el.style.transform = 'none';
}

frame() {
  const root = this.rootRef.current; if (!root) return;
  const vh = window.innerHeight;
  // 92% of the viewport: it starts before the block is fully on screen
  root.querySelectorAll('[data-reveal][data-rv="hidden"]').forEach(el => {
    const rc = el.getBoundingClientRect();
    if (rc.top < vh * 0.92 && rc.bottom > -40) this._show(el);
  });
}

Markup side

data-reveal · data-riseline

Nothing else. No animation CSS on the element, no delays in the template.

<span data-reveal="up" style="display:inline-flex;">…</span>
<h2 data-reveal="rise">
  <span data-riseline="" style="display:block;">Questions,</span>
  <span data-riseline="" style="display:block;">answered.</span>
</h2>
