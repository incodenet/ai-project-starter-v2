03, Usage Rules

How to Apply It

Headings & hero → Hanken

All h1–h6, hero text and the UPPERCASE eyebrow captions above headings use var(--font-heading) / var(--font-caption). Kept for brand recognition.

Everything else → Jakarta

Body copy, buttons, nav links, menus, tabs and form fields all use var(--font-body). This is the site's default voice.

One source of truth

Families live in hi-fonts.css; roles & scale in hi-typography.css. Every page links both, edit once, applies everywhere.

Resilient fallbacks

Every reference is var(--font-x, 'Real Font', system-ui, sans-serif), so type never breaks even if the token file fails to load or in an offline build.
